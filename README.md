# Burkina Solar Energy — Site Vitrine

Projet web complet pour BSE, Ouagadougou, Burkina Faso.

## Structure
- `bse-backend/` — API REST Node.js/Express + MySQL
- `bse-admin/` — Backoffice React (port 3000)
- `bse-vitrine/` — Site vitrine React (port 3001)

## Démarrage local
```bash
# Backend
cd bse-backend && npm install && npm start

# Backoffice
cd bse-admin && npm install && npm start

# Vitrine
cd bse-vitrine && npm install && npm start
```
